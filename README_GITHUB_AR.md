# NEXBOTS — Android + Website

هذه نسخة المصدر الموحّدة لموقع NEXBOTS وتطبيق أندرويد. واجهة التطبيق لا تعرض تعليمات تشغيل للمستخدم.

- `site/`: موقع React، منشور منفصلًا على Cloudflare Pages.
- `android/`: تطبيق Kotlin يعرض موقع NEXBOTS الحي، مع الدخول الأصلي لحساب Google، والتنزيلات، وإشعارات Firebase، ووضع دون اتصال للواجهة فقط.
- `.github/workflows/build-android-apk.yml`: بناء APK تلقائيًا في تبويب Actions في GitHub بعد رفع الملفات **مفكوكة من ZIP** إلى جذر المستودع، أو يدويًا من `Run workflow`.

## شروط الإطلاق الحقيقي

1. Google Sign-in: أدخل SHA-1 وSHA-256 للشهادة التي وقعت APK في Firebase؛ الملف الموجود `firebase-client-config.json` هو إعداد **عميل** وليس بيانات خادم سرية. بعد تسجيل SHA، استخدم `FIREBASE_ANDROID_JSON_B64` (ملف JSON المحدث بترميز Base64) من GitHub Secrets، أو حدّث `android/firebase-client-config.json` بالإعداد الجديد.
2. لضمان نفس بصمة توقيع النسخ التجريبية استخدم GitHub Secret باسم `NEXBOTS_TEST_KEYSTORE_B64` (Base64 لمفتاح الاختبار السابق)، ولا تنشر المفتاح داخل المستودع. دون ذلك يُنشأ مفتاح تجريبي لدى GitHub Runner وتختلف البصمة عند إعادة البناء.
3. النشر الإنتاجي يحتاج **مفتاح توقيع Release مستقل وآمن**، واختبار Google وFCM وتنزيل الملفات على هاتف، والتحقق من إعداد خادم إشعارات Cloudflare. APK الناتج هنا `debug` قابل للتثبيت للاختبار وليس إصدارًا معتمدًا للمتجر.
4. الموقع يُحدّث داخل التطبيق بعد نشر ملفات `site` في Cloudflare لأنه متصل بعنوان `https://nexbots.pages.dev`. التغييرات على كود Kotlin أو صلاحيات أندرويد تحتاج إصدار APK جديدًا.
5. وضع انقطاع الاتصال يعرض واجهة أقسام محلية فقط دون استرجاع الرسائل أو الملفات أو بيانات المستخدم الخاصة.

**لا تُدرج مفاتيح خدمات Firebase الإدارية أو Cloudflare API Tokens أو مفاتيح توقيع الإنتاج داخل المستودع أو ZIP.**
