NEXBOTS v1.3 — الإصلاح والتصميم الراقي

الملفات المعدّلة فقط:
- src/App.jsx — شعارات Google والتواصل من داخل التطبيق، تحسين صور الحساب، عرض مزايا الباقات، نسخة v1.3
- src/lib.js — تضمين SVG رسمياً داخل حزمة JavaScript، ومميزات الاشتراكات الافتراضية
- src/styles.css — خط جديد وأزرار وحركات ولمسات بنفسجية/ذهبية
- index.html — تحميل خطوط Alexandria وIBM Plex Sans Arabic وOutfit
- server/firestore.js — عدم حفظ id و _updateTime في مستندات Firestore
- server/api.js — معالجة خطأ رفع صورة البروفايل، تنظيف الملف الفاشل في R2، ونصوص توضيحية
- server/constants.js — تحديث المزايا الافتراضية للباقات
- tests/* — اختبارات إضافية

خطوات النشر:
1. فك ZIP الصغير، وارفع الملفات بمساراتها الأصلية إلى GitHub في فرع main (استبدل القديم، لا ترفع ZIP كملف).
2. سيقوم Cloudflare Pages بالنشر تلقائياً؛ تأكد من نجاح Deployments.
3. جرّب تغيير صورة البروفايل باسم حسابك.
4. إذا ظهر خطأ صلاحيات Firestore مجدداً، تأكد من نشر قواعد v1.1/v1.2 الموجودة داخل المشروع في Firestore Database → Rules. هذا الإصدار لا يطلب قواعد جديدة.
5. لا تضف مفاتيح Firebase Admin إلى GitHub أو أي موقع.
6. إذا بقيت أيقونة قديمة، افتح الموقع بتبويب خاص أو بعد تحديث الصفحة؛ الأيقونات الآن مضمنة داخل JS ولا تعتمد على public/icons.

مهم: مزايا الباقات الموضحة تستخدم ميزات موجودة حالياً في المنصة، وليست وعوداً بوظائف غير منفذة. المالك يستطيع تغيير السعر والمميزات من لوحة التحكم. إذا كنت حفظت باقات خاصة من قبل، لن يمحوها التحديث.
