# NEXBOTS Android / PWA — تحديث مساعد للإصدار v2.8

هذا تحديث تجريبي لإضافة **PWA وفتح الواجهة العامة دون إنترنت** إلى إصدار NEXBOTS v2.8، مع ملف HTML مستقل لبرامج تحويل HTML إلى APK. لا يعد تطبيق APK أصلياً ولا يفعّل إشعارات الخلفية من تلقاء نفسه.

## 1. ما الذي يعمل بعد تركيب التحديث على الموقع؟
- `manifest.webmanifest` يجعل الموقع قابلاً للتثبيت من Chrome على أندرويد.
- `sw.js` يخزن ملفات الواجهة التي سبق تحميلها، ويجرب الشبكة أولاً عند فتح الصفحات.
- `GET /api/public` و`GET /api/projects` فقط يمكن الرجوع لآخر نسخة عامة محفوظة منهما. لا تُخزن بيانات الرسائل الخاصة أو الإدارة أو الاشتراكات أو المدفوعات في كاش Service Worker.
- عمليات الدفع والرفع والإرسال لا تعمل بلا اتصال، ويظهر شريط إرشادي بوضع المشاهدة.
- عندما تتصل بالإنترنت، يستعلم المتصفح عن تحديث `sw.js` ويمكنه تحميل آخر ملفات الموقع دون توزيع APK جديد. التحديث لا يجبر الصفحة المفتوحة على إعادة التحميل حتى لا يخسر المستخدم رفعاً جارياً أو نموذجاً يكتبه.

**الحدود:** يجب فتح الموقع أولاً عبر الإنترنت وتصفح المحتوى المراد تخزينه. الصور والرسائل والمحادثات الخاصة لا تتوفر كلها بلا اتصال. لا يمكن التعهد بالتصفح الكامل دون شبكة دون تطوير نسخ محلية آمنة لبيانات المستخدم في IndexedDB وإدارة تسجيل الخروج والحذف. تخزين المتصفح قابل للمسح من النظام.

## 2. إذا أردت APK بإشعارات فعلية والجهاز مغلق

الملف `NEXBOTS_ANDROID_HTML_LAUNCHER.html` يفتح NEXBOTS، لكنه **لا يضيف إشعارات Push حقيقية ولا يضمن تخزين WebView**. معظم محولات HTML البسيطة تعمل بتقنية WebView، وقد لا تدعم Push API. الأفضل استخدام PWA مع Chrome (ثم **Trusted Web Activity / Bubblewrap**) أو APK أصلي يدعم Firebase Cloud Messaging.

لكي تصل رسائل خاصة إلى شريط الإشعارات والتطبيق مغلق يلزم:
1. إعداد Firebase Cloud Messaging لمشروع Firebase الحالي، مع مفتاح **Web Push VAPID public key** للموقع أو تكامل FCM أصلي للأندرويد.
2. حفظ رموز الأجهزة الآمنة بعد موافقة المستخدم على الإشعارات.
3. إرسال رسائل FCM من خادم Cloudflare بعد حفظ رسالة جديدة في قاعدة البيانات، باستهداف المستلم فقط، وعدم إرسال البيانات السرية إلى جهاز غير مخول.
4. التعامل مع تسجيل الخروج وإبطال الرموز والأجهزة غير النشطة وموافقة إشعارات Android 13+.

لم ننفذ هذه النقاط في هذا التحديث، لأن ربط الإشعارات يحتاج إعدادات مشروعك وصلاحيات خادم لم تُقدَّم هنا.

## 3. طريقة التركيب

- خذ نسخة احتياطية من مشروع v2.8.
- استبدل الملفات الموجودة في ZIP جزئي داخل مشروع v2.8 مع الحفاظ على بقية الملفات.
- نفّذ `npm install` ثم `npm run build` في جهازك أو GitHub Actions.
- انشر ناتج `dist` في Cloudflare Pages. **لا يحتاج هذا التحديث إلى تعديل قواعد Firestore.**
- افتح `https://nexbots.pages.dev/` في Chrome على أندرويد أثناء الاتصال، ثم اختر «إضافة إلى الشاشة الرئيسية/تثبيت التطبيق».
- تنقل بين الرئيسية واستكشاف المشاريع، اقطع الإنترنت وجرّب إعادة فتح التطبيق.

## 4. ما هو الأفضل في تطبيق تحويل HTML إلى APK الذي عندك؟

إن كان يسمح بإدخال `Website URL` استخدم مباشرة `https://nexbots.pages.dev/` بدل صفحة HTML محلية.
إن كان يقبل HTML فقط، استخدم ملف `NEXBOTS_ANDROID_HTML_LAUNCHER.html` ثم فعّل JavaScript وDOM Storage والإنترنت وصلاحية اختيار الملفات في إعدادات المحوّل. لا تستخدم IFRAME، لأن NEXBOTS يرسل `X-Frame-Options: DENY` لحماية الحسابات.

التحديث لا يمس نظام رفع الملفات ولا قواعد الدفع ولا Firebase الخاصة بالموقع.
